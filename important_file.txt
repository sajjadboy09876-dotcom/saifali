The Two Main Uses of git checkout
1. Switch Between Branches
bash
git checkout main
# → Moves you to the main branch

git checkout new-feature
# → Moves you to the new-feature branch
2. Go Back to Old Commits
bash
git checkout a3f2b8c
# → Takes you back to an old commit (like time travel!)
